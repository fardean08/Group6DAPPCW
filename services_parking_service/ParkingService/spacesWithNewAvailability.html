Returns the subset of spaces whose ParkingSpace.availableSpaces has increased since the last refresh (i.e. spaces that were recently freed up).

Used by ParkingHomeScreen to trigger a snackbar notification when previously-full spaces become available.

Implementation

List<ParkingSpace> spacesWithNewAvailability(List<ParkingSpace> spaces) {
  return spaces
      .where(
        (space) => space.availableSpaces > space.previousAvailableSpaces,
      )
      .toList();
}
