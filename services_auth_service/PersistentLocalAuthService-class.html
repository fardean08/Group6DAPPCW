PersistentLocalAuthService

PersistentLocalAuthService class

AuthService backed by SharedPreferences for offline / no-Firebase use.

User accounts and the active session are serialised to JSON and stored in the device's SharedPreferences so that signing in persists across app restarts. This implementation is selected automatically in main when Firebase initialisation fails.
